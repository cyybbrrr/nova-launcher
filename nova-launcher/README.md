# Nova Launcher

## Install dependencies
```bash
npm install
```

## Run the built app locally
```bash
npm start
```

## Development mode
Open two terminals in this folder. In terminal 1:
```bash
npm run dev
```
In terminal 2:
```bash
npm run dev:electron
```

## Build Windows installer and portable EXE
```bash
npm run dist
```

Build outputs are written to `release/`.
